## Local Setup

### 1. Clone the repository

```bash
git clone https://github.com/Naveen9634/tactyqal-homepage-redesign.git
cd tactyqal-homepage-redesign
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Open the local URL shown in your terminal.
